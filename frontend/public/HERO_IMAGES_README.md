# Hero Slider Images Guide

## Required Images

The hero slider needs 3 healthcare-related images. Please add these images to the `frontend/public/` folder:

### 1. `/hero-medical-team.jpg`
**Recommended theme:** Medical professionals, doctors, healthcare team
- **Size:** 1920x1080px or larger (16:9 aspect ratio recommended)
- **Content suggestions:**
  - Medical team working together
  - Doctors in a hospital setting
  - Healthcare professionals with technology
  - Modern medical facility

### 2. `/hero-medical-records.jpg`
**Recommended theme:** Medical records, digital health, data security
- **Size:** 1920x1080px or larger (16:9 aspect ratio recommended)
- **Content suggestions:**
  - Digital medical records on tablet/computer
  - Secure data storage concept
  - Medical documents with privacy focus
  - Healthcare technology interface

### 3. `/hero-healthcare-technology.jpg`
**Recommended theme:** Healthcare technology, mobile health, accessibility
- **Size:** 1920x1080px or larger (16:9 aspect ratio recommended)
- **Content suggestions:**
  - Person using mobile device for health
  - Healthcare app interface
  - Telemedicine concept
  - Modern healthcare technology

## Image Requirements

- **Format:** JPG or PNG
- **Aspect Ratio:** 16:9 (landscape) recommended
- **Resolution:** Minimum 1920x1080px for best quality
- **File Size:** Optimize images to under 500KB for faster loading
- **Style:** Professional, modern, healthcare-focused

## Free Image Resources

You can find free healthcare images from:
- **Unsplash:** https://unsplash.com/s/photos/healthcare
- **Pexels:** https://www.pexels.com/search/healthcare/
- **Pixabay:** https://pixabay.com/images/search/medical/

## Image Optimization

Before adding images, optimize them using:
- **TinyPNG:** https://tinypng.com/
- **Squoosh:** https://squoosh.app/
- **ImageOptim:** For Mac users

## Current Implementation

The hero slider includes:
- ✅ Zoom effect (Ken Burns animation)
- ✅ Smooth fade transitions between slides
- ✅ Overlay for text readability
- ✅ Responsive design
- ✅ Fallback gradient if images don't load

## Customization

If you want to use different image names or add more slides, update the `heroSlides` array in `frontend/src/pages/LandingPage.jsx`.
